# url-cleaner

A lightweight Next.js app that strips tracking parameters (UTM, Facebook, Google, etc.) from URLs.

## Features

- Paste any URL and remove tracking clutter
- One-click copy of the cleaned URL
- Supports utm_source, utm_medium, utm_campaign, utm_term, utm_content, fbclid, gclid, ref, source, mc_cid, mc_eid

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
